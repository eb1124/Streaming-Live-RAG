# Foundational RAG baseline: integration evaluation 2026-09-28

This is the frozen baseline for all later work (AdaptiveRAG). Git tag: `rag-baseline-2026-09-28`.

* Command: `python -m evaluation.integration.run --runs 2` (existing harness, cases and configuration; nothing
  was changed before, during or after the runs).
* Pipeline: dense (arctic-m) + BM25 → RRF → temporal resolution → top-20 pool → cross-encoder rerank → top 10 →
  context (max 6 sources) → Groq `openai/gpt-oss-20b`, prompt `grounded-qa-2`, temperature 0, seed 1234 →
  deterministic verification → cited answer or abstention.
* Offline suite at this commit: 243 passed, 1 skipped.
* Files: `run-1.json`, `run-2.json` (every stage of every case), `summary.md` (automatic checks),
  `agreement.json` (run-to-run agreement).

**Historical files:** `report.md` and `manual_review.json` describe the earlier 2026-09-26 runs with prompt
`grounded-qa-1`. They are kept unchanged as history and do **not** describe the runs in this directory.
`summary.md` still points to `report.md` for the manual review; this file is the review of the 2026-09-28 runs.

## Known limitations carried forward

* Version-neutral questions whose versions disagree (`i-uc-neutral-card`): the model merges the versions; the
  verifier rejects the merge, so the user gets the fixed abstention instead of both versions' rules.
* A model that wraps quotes in literal quotation marks fails verification (strict format).
* The automatic fact checks are exact-phrase regexes; they are not a correctness verdict.
* The rate-limit error text recorded in `run-*.json` includes the Groq organization id (an identifier, not a
  credential). No API key appears in any result file.
