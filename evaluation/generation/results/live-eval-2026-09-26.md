# Live generation evaluation, 2026-09-26

Provider Groq, model `openai/gpt-oss-20b`, prompt `grounded-qa-1`; settings: temperature 0, seed 1234,
reasoning effort medium, max 4096 completion tokens. 13 cases × 2 runs
(`python -m evaluation.generation.run --runs 2`).

Raw outputs: `run-1.json`, `run-2.json`. Auto-generated table: `report.md`.

**Scope.** This is a 13-case behavioral check of grounding, citation and abstention, not an
answer-quality benchmark. "Passed verification" means only that each claim cited existing sources, its
quotes occur in them, and its numbers occur in them. It does **not** mean the answer is correct or
complete. Nothing was tuned in response to these results.

## What this shows

**Grounding and citations (what the verifier and checks measure)**
* No answer cited a chunk outside the context or a wrong-organization or wrong-version source.
* No required citation was missed.
* All three unanswerable cases abstained with the fixed response, including the February-version trap.
* The one verifier rejection (g-conflict run 1) came from the model wrapping real quotes in literal `"`
  characters. The quote check does not strip those, so this was a strict-format rejection. The claim itself
  also merged the two versions.
* The one API failure (HTTP 429, rate limit) failed safe: the fixed abstention, no partial answer.

**Answer quality (not measured by the verifier)**
* **Version merging is not prevented.** g-conflict run 2 passed every automated check while giving the
  February rule as if it applied to both versions. Prompt rule 6 was not followed, and quote/number
  verification cannot detect it, because each quote is genuine.
* **Semantic distortion passes verification.** g-e2e-tips cites the right clause and quotes "maximum of up
  to 20%", but misstates what the 20% applies to.
* **Omissions.** g-citation run 1 and g-version-july gave true but incomplete answers.
* The suite's own checks are both too lenient (g-conflict run 2 passed) and too narrow in places (exact
  phrases like "personal credit card"). They were not changed after seeing results.
